데이터 마이너는 엘든링 게임 파일에서 미사용 보스 모델을 발견했다. 이들이 이 발견으로부터 추측하고 분석한 이유는, 그들은 "게임 난이도가 높으므로 실제로 사용되지 않았던 무기 모델은 기획 의도를 제대로 반영하지 못할 것"이라고 주장한다.

데이터 마이너와의 갈등은 '오류코드'를 통해 극명하게 드러났다. 보스 모델 중 하나는 오류코드 560으로 표시되어 있었는데, 이 코드가 실제 게임에서 사용되지 않은 이유를 설명했다. 데이터 마이너는 "그 코드는 기획 의도를 반영하지 못했거나, 실제 게임에서 수정된 것"이라고 분석했다.

구체성 원칙
데이터 마이너들이 발견한 오류코드 560은 실제로 엘든링 게임 파일을 정확하게 불러올 때 나타났다. 이 코드는 보스 모델 중 하나와 연결되어 있었는데, 데이터 마이너들은 그 코드가 실제 보스의 기획 의도를 제대로 반영하지 못했거나 수정되었음을 확인했다.
